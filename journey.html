Support

What closes the gap

The next build work is release proof.

  • Sign and notarize: add Developer ID signing and notarization before broad distribution.
  • Record clean installs: capture clean-machine install, Logic, Ableton, and session recall evidence.
  • Verify upgrade: prove Lite-to-Full install behavior and user copy before opening paid traffic.
  • QA checkout: verify product names, prices, receipts, fulfillment, and purchase support in the checkout account.
