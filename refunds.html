Purchase expectations

Clear help beats refund confusion.

Every buyer should know what they bought, how delivery works, what version scope means, and what to send if install fails.

Purchase basics

  • Receipt: product name, platform, version scope, and delivery method.
  • Delivery: installer delivery and license instructions should be clear.
  • Support: refund and install questions route to one clear inbox.

License scope

Current major version

Purchases should clearly state current major-version access unless the checkout receipt says otherwise.

Install issue

Support first

For failed installs, support needs the order email, product, macOS version, DAW, and screenshot of the issue.

Refund request

Human review

Refund requests should start with support so install issues can be understood before a final decision.
