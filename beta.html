What gets measured

Investor proof is more than download count.

  • Install proof: package delivered, installer completed, DAW scan passed.
  • Usage proof: plugin opened, audio processed, session saved and reopened.

  • Quality proof: support issue count, severity, fix status, testimonial permission.
