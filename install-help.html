Mac plugin install

Know what should happen before you open the DAW.

The beta install path is Mac-first. Public installers are not live yet; these notes define the quality bar for a smooth user experience.

Send support this

  • Product name and Lite or Full version.
  • macOS version and Mac chip type.
  • DAW name and version.
  • Screenshot of the plugin scan or error.

Step 1

Install

Run the approved installer package, then restart the DAW before looking for the plugin.

Step 2

Scan

Logic should scan Audio Units when it opens. Ableton Live support is pending a separate QA pass.

Step 3

Verify

Open the plugin on audio, pass signal through it, save the session, close it, and reopen it.

Expected Mac locations

The files should land where a DAW can scan them.

  • Audio Units: /Library/Audio/Plug-Ins/Components/
  • VST3: /Library/Audio/Plug-Ins/VST3/
  • Support files: /Library/Application Support/Fix Your Sound/
  • Support screenshot: send the folder view or DAW scanner result if the plugin does not appear.

Logic Pro pass

Audio Units scan

Restart Logic, open Plug-In Manager, confirm the plugin validates, insert it on an audio track, then save and reopen the session.

Ableton status

Pending QA

Do not treat Ableton Live as verified yet. We will publish Ableton-specific scan and session-recall steps after QA is complete.
