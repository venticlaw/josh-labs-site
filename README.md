# Fix Your Sound Site

Static GitHub Pages site for the Fix Your Sound plugin startup.

## Scope

- Plugin-first brand site.
- Products: Your Mix Sucks, BassPhat, Plugin Suite.
- Direct Lemon Squeezy checkout links for current products.
- Support and install guidance for Mac AU rollout.

Fix Your Sound is the separate plugin-startup brand/project and intended DBA. JoshYouWut remains the producer/music-services brand. This site intentionally excludes beat store, sync, and mixing-service commerce.
